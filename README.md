## 📊 Project Overview
An interactive and dynamic Excel data analytics solution built to analyze **$9.29 Million** in retail revenue across 2,000 transactions. This project tracks key business metrics including profit drivers, regional breakdowns, category performance, and operational order quantities to assist stakeholders in data-driven decision making.

## 📈 Key Insights & Business Findings
* **Top Revenue Driver (Region):** The **West Region** led overall performance with **$2.45 Million** in sales, closely followed by the East Region ($2.37M).
* **Core Product Categories:** **Office Supplies** generated the highest demand, accounting for over **$5.09 Million** (more than 54%) of total sales revenue. 
* **Seasonal Sales Peaks:** Monthly sales peaked significantly in **March ($947K)** and **October ($879K)**, pointing to major quarterly demand spikes.
* **Volume Analysis:** Total inventory moved was **9,853 units**, with the highest order volume correlation matching high total transaction pricing.

## 🛠️ Advanced Features & Excel Techniques Used
* **Data Visualizations & Pivot Charts:** * Trend lines for monthly sales and order quantity comparisons (Combo Chart).
  * Category breakdown using percentage-based Pie charts.
  * Regional comparisons using custom Column and Stacked charts.
* **Look-up & Retrieval Systems:** Developed a dedicated analytical lookup sheet utilizing advanced reference formulas (`VLOOKUP` / `XLOOKUP` / `INDEX & MATCH`) to instantly extract transaction and customer insights.
* **Data Processing:** Cleaned and structured 2,000 raw transaction rows ensuring data integrity for calculations like `SUMIFS` and `AVERAGEIFS`.

## 📂 Repository Contents
* `Superstore Dashboard.xlsx`: The main workbook containing the raw transaction data, pre-calculated pivot tables, advanced formulas, and interactive dashboard charts.
* `README.md`: Project summary and executive documentation.
